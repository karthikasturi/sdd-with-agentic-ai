# Exhibit A — The Prompt

This is the entire input given to the agent for this exhibit. No constitution, no spec, no repo conventions — just a one-line ask dropped into an empty directory, which is how most "vibe coding" sessions start.

> build me an api to track equipment sensor alerts. equipment sends in readings, and if something's wrong we should alert someone.

The output on the other side of this prompt is captured verbatim in `output/`, with no cleanup — the rough edges are the point. `NOTES.md` lists what actually went wrong and why each one is a predictable consequence of skipping the spec-driven steps, not a one-off mistake.
